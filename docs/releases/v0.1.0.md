# ProbeOS v0.1.0

ProbeOS v0.1.0 is the first qualified public release of the lightweight,
bootable Linux environment for hardware inspection, diagnostics, and
performance benchmarking.

It includes Hardware Identification v1 with authoritative `report.txt` and
`report.json`, local TUI/GUI access, the retro-friendly Web UI and read-only
`/api/v1` API, wired DHCP/LAN operation, offline use, privacy-redacted network
views, and open-source Memtest86+ 8.10.

Four images are provided: x86_64 GRUB (BIOS and x86_64 UEFI), x86_64 SYSLINUX
(BIOS), x86 GRUB (BIOS), and x86 SYSLINUX (BIOS). Linux and Memtest86+ startup
passed on all five corresponding QEMU SeaBIOS/OVMF paths using TCG. This is not
a claim of exhaustive physical-hardware compatibility. Secure Boot, IA32 UEFI,
ARM, installation/persistence, and Internet-facing Web operation are outside
this release. See `docs/release-readiness.md` for the complete matrix and known
limitations.

Download all four ISOs only if you need every variant. Verify files from the
download directory before use:

```sh
sha256sum -c SHA256SUMS
```
