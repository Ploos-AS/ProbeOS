with the same project contributor; no outside contributor is present. Existing
copyright notices identify Ploos AS, which has authorized relicensing the
ProbeOS-authored material to GPL-3.0-or-later.

practical. The repository `LICENSE` applies to other ProbeOS-authored
documentation, workflow definitions, configuration, tests, fixtures, and
assets unless a file states otherwise. Generated files are not independently
relicensed by their generation. Third-party packages and generated boot
payloads are governed by their upstream licenses and are inventoried at
release time; no third-party source or binary is committed directly here.

entire composite ISO is solely GPL-3.0-or-later.
